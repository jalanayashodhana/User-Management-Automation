## 🚀 About the Project

**User Management Automation** is a Bash scripting project designed to simplify common Linux user and file-permission management tasks.

The project demonstrates how shell scripting can reduce repetitive manual work, improve consistency, and support efficient Linux system administration.

## ✨ Features

- 👤 **User Management** — Automate common user administration tasks.
- 🔐 **Permission Checker** — Inspect file permissions, ownership, and group information.
- 📁 **File & Directory Validation** — Check whether a specified path exists.
- 📊 **Permission Reporting** — Display permission details using Linux commands.
- 🛡️ **Input Validation** — Handle invalid or missing paths appropriately.
- ⚡ **Automation** — Reduce repetitive command-line administration tasks.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Bash | Automation and scripting |

| `chmod` | Manage file permissions |

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jalanayashodhana/User-Management-Automation.git
```

### 2. Navigate to the project directory

```bash
cd User-Management-Automation
```

### 3. Make the script executable

```bash
chmod +x "userMn (1).sh"
```

### 4. Run the script

```bash
./"userMn (1).sh"
```

If the script requires administrative privileges for particular operations, run it with the appropriate permissions.

> **Note:** Run this project in a Linux environment such as Ubuntu, a Linux virtual machine, or WSL. Review the script before running it with elevated privileges.
